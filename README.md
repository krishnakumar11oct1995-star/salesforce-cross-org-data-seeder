# Salesforce Cross-Org Data Seeder (Chrome Extension)

> Manifest V3 Chrome Extension for Salesforce relational data migration, schema pre-validation, and predictive storage sizing.

## 🚀 Key Features
- **Cross-Org Migration:** Seed relational records directly between Salesforce orgs.
- **Schema Pre-Validation:** Validates source vs destination field schemas, types, and constraints before deployment.
- **Parent-Child Linker:** Automatic resolution and mapping of lookup and master-detail relationships.
- **Mock Data Generator:** Synthesizes realistic test records adhering to object schemas.
- **Predictive Storage Sizing:** Calculates expected storage footprint across destination objects.

## 🛠️ Tech Stack
- Chrome Extension API (Manifest V3)
- TypeScript / JavaScript
- Vite & Vitest
- Tailwind CSS
